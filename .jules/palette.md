# Palette Journal

## 2025-05-15 - Modal Accessibility and UX Patterns
**Learning:** React modals require explicit focus management (aria-modal, roles), keyboard handling (Escape key), and scroll locking to meet modern UX and accessibility standards.
**Action:** Always implement `role="dialog"`, `aria-modal="true"`, Escape key listeners, and `body` scroll locking for new modal components.
