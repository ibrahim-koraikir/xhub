## 2025-06-20 - Semantic Lists for Step-by-Step Guides
**Learning:** Using semantic `<ol>` and `<li>` structures for sequential steps (like an installation guide) provides inherent hierarchy and progress information to screen reader users that generic `div`s lack.
**Action:** Always prefer semantic list elements for sequential or categorized information blocks.

## 2025-06-20 - Essential Modal Accessibility
**Learning:** A truly accessible modal requires three key technical pillars: focus trapping within the dialog, body scroll locking to prevent context loss, and keyboard support for the 'Escape' key to ensure a predictable exit path.
**Action:** Implement these three pillars as a standard pattern for all custom modal components.
