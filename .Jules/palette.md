## 2026-07-05 - [The Four-Pillar Accessible Modal Pattern]
**Learning:** A truly accessible modal requires four simultaneous pillars: (1) Keyboard support via Escape key listeners, (2) Background scroll locking to maintain context, (3) Programmatic accessibility using role='dialog' and proper ARIA labeling, and (4) Semantic content structure (like <ol> for steps) to ensure logical screen reader navigation.
**Action:** Always implement these four pillars together in every modal component to ensure a consistent and inclusive user experience.
