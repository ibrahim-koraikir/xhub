# Palette's Journal - XHub

## 2025-05-14 - Modal and Interactive Elements Accessibility
**Learning:** For dark-themed, glassmorphic UIs, focus rings need a dark offset (`focus-visible:ring-offset-black`) to remain visible against dark backgrounds. Modal components should always include body scroll locking and Escape key listeners to meet basic accessibility standards.
**Action:** Apply standardized `focus-visible:ring-2 focus-visible:ring-brand-500 focus-visible:ring-offset-2 focus-visible:ring-offset-black outline-none` to all interactive elements in dark-mode apps.
