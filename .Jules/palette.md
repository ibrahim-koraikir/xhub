## 2026-06-29 - Skip to Content for Landing Pages
**Learning:** For single-page landing pages with fixed headers and many sections, a skip-to-content link is essential for keyboard users to bypass navigation and jump to the core content.
**Action:** Always include a skip-to-content link as the first focusable element in the application root, using Tailwind's `sr-only focus:not-sr-only` classes to keep it visually hidden until focused.
