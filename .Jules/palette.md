## 2026-07-01 - [Skip Link Accessibility Pattern]
**Learning:** Using 'sr-only focus:not-sr-only' with a target ID and 'tabIndex={-1}' is a standard, non-intrusive way to provide immediate keyboard accessibility in a monolithic landing page layout.
**Action:** Always implement a skip-to-content link as the first focusable element in large single-page applications to improve keyboard navigation efficiency.
